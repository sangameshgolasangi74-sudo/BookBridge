# BookBridge

**BookBridge – Your Digital Library, Buying, Borrowing and Book Exchange Platform**

BookBridge is a digital platform designed to connect book readers, buyers, sellers and borrowers in one place.

## Features

- Browse and explore books
- Buy and sell books
- Borrow and return books
- Exchange books
- Digital library and reading
- Customer dashboard
- Owner dashboard
- Admin dashboard
- User registration and login
- Book management and order tracking

## Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Express.js
- Node.js
- SQLite

## Run Locally

### Prerequisites
- Node.js
- npm

### Installation

```bash
npm install
```

### Start development server

```bash
npm run dev
```

Open the local URL shown in your terminal.

### Build for production

```bash
npm run build
```

### Start production server

```bash
npm start
```
